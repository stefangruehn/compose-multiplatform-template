# Changelog

All notable changes to the app are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## 0.2.0

### Added

- The menu keeps its folded groups between runs, and every page opens where it was left, also after a restart.

### Changed

- The menu scrolls, so Exit is in reach on a short screen without folding a group away.

## 0.1.0

### Added

- Initial template: menu with page groups, an example page, settings for theme and start page, and
  pages for help, imprint, privacy, this changelog and the open-source libraries.
